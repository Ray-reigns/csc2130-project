About Our Trading Web Application

Project Overview

LoydeTrade is a simple and secure web-based web application developed for CSC2130 Web Development. It allows users to creat accounts that enable then intaract globally,and to trade globally

Problem Statement

Many small-scale traders in Kenya lack a digital platform to showcase their products, manage orders, and reach customers. Our app solves this by bringing the market online.

Key Features of the System

  • User Registration and Login System
  • Product Listing with Images and Prices
  • Shopping Cart and Checkout
  • Order Management Dashboard
  • Secure Contact and Support Page
  • Admin Panel to Manage Products

Technologies Used

Frontend: HTML5, CSS3, JavaScript
Backend: PHP (for XAMPP)
Database: MySQL
Server: Apache (XAMPP)
